# Intelligent Recruitment and Talent Acquisition Platform

## DSA-II Project

This project demonstrates the application of Data Structures and Algorithms to an Intelligent Recruitment and Talent Acquisition Platform.

The system conceptually manages candidate information and relationships between candidates, skills and job requirements.

## DSA Concepts Used

### 1. Binary Search Tree (BST)
Candidate records are organized using candidate IDs to support efficient searching and ordered storage.

### 2. AVL Tree
An AVL Tree is used to maintain balanced candidate records and support efficient searching.

### 3. Min Heap
A Min Heap is used to prioritize candidates according to their suitability scores, with lower scores having higher priority in the Min Heap demonstration.

### 4. Max Heap
A Max Heap is used for priority-based candidate ranking, allowing candidates with higher suitability scores to be accessed first.

### 5. Graph
A graph represents relationships between candidates, skills and job requirements.

### 6. Adjacency Matrix
The graph is represented using an adjacency matrix to store connections between vertices.

### 7. Adjacency List
The same graph is also represented using an adjacency list for storing connected vertices.

## Project Features

- Candidate record management
- Candidate searching using BST
- Balanced searching using AVL Tree
- Priority handling using Min Heap
- Candidate ranking using Max Heap
- Graph representation of recruitment relationships
- Adjacency Matrix representation
- Adjacency List representation
